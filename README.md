# نيكست الصوتي — النسخة الأولى

مكالمة صوتية حية مع نيكست من الجوال. الصوت والتفكير الحي من **Gemini 3.8 Live**، والقراءة من الـ Vault عبر GitHub، والكتابة في `Inbox/` فقط.

## كيف يعمل

```
الجوال (صفحة ويب)  ⇄  Gemini Live  (صوتك ↔ صوته، مباشرة)
        │
        └── GitHub API ── مستودع الـ Vault الخاص
              ├─ يقرأ .next-voice/index.json  (بحث، قراءة ملف، Open Loops)
              └─ يكتب Inbox/<تاريخ> صوتي - <عنوان>.md

الماك (كل 10 دقائق، حين يكون مفتوحاً):
  next_voice_sync.py → يبني الفهرس → commit → pull → push
```

- لا يوجد خادم، والتكلفة الثابتة صفر. تدفع فقط ثمن دقائق Gemini.
- الشخصية تُقرأ من الـ Vault في بداية كل مكالمة من أربعة ملفات: `_System/Voice Assistant.md` و`identity.md` و`soul.md` و`user.md`. أي تعديل فيها يظهر في المكالمة التالية بعد المزامنة.
- المفاتيح تُحفظ في متصفح الجوال فقط، ولا توجد في الكود.

## الملفات

| الملف | الغرض |
|---|---|
| `web/index.html` و`web/app.js` | التطبيق: صفحة واحدة بلا خطوة بناء |
| `web/manifest.webmanifest` والأيقونات | للإضافة إلى الشاشة الرئيسية |
| `sync/next_voice_sync.py` | يبني الفهرس ويزامن الـ Vault مع GitHub |
| `sync/com.elwalid.nextvoice.sync.plist` | قالب مهمة launchd تشغّل المزامنة كل 10 دقائق |
| `sync/vault.gitignore` | يصبح `.gitignore` للـ Vault |

## ما تفعله أنت (مرة واحدة)

### 1) مفتاح Gemini
1. افتح https://aistudio.google.com/apikey ثم اختر **Create API key**.
2. **فعّل الفوترة** للمشروع. هذا ضروري، لأن شروط Gemini API تنص على أن بيانات الطبقة المجانية تُستخدم لتحسين منتجات Google وقد يراجعها بشر. الـ Vault فيه بيانات شخصية وبيانات عملاء، والطبقة المدفوعة لا تُستخدم بياناتها في التدريب.
3. في Google Cloud Billing، أنشئ **Budget alert** بقيمة 10$.

### 2) GitHub
1. أنشئ مستودعاً **خاصاً** باسم `My-Vault`.
2. أنشئ مستودعاً **عاماً** باسم `next-voice` للصفحة. لا يحتوي أي سر.
3. أنشئ رمزاً من Settings ← Developer settings ← **Fine-grained tokens**:
   - Repository access: `My-Vault` فقط.
   - Permissions: **Contents: Read and write**.
   - Expiration: سنة.

### 3) أخبر نيكست باسم مستخدم GitHub
وبعدها ينفّذ نيكست ما يلي:
- يحوّل الـ Vault إلى مستودع git ويضيف `.gitignore`.
- يجهّز مهمة المزامنة على الماك.
- يجهّز ملفات الصفحة للرفع.

## المكالمة
- افتح الصفحة في Safari ثم اختر **مشاركة ← إضافة إلى الشاشة الرئيسية**.
- من ⚙︎ أدخل المفتاح والرمز و`elwalidhafiz-svg/My-Vault`، ثم اضغط «اختبار الـ Vault».
- اضغط **اتصل**. تستطيع مقاطعته في أي وقت. خانة الكتابة متاحة إن كان المكان صاخباً.

## حدود معروفة (النسخة الأولى)
- **يجب أن تبقى الشاشة مفتوحة.** في iPhone يتوقف المايك في المتصفح إذا قُفلت الشاشة. الصفحة تطلب إبقاء الشاشة مضاءة تلقائياً. هذا مناسب في السيارة بحامل جوال، وأقل راحة أثناء المشي.
- **الفهرس يتأخر حتى 10 دقائق** عن الـ Vault، ولا يتحدث إلا والماك مفتوح.
- **لا واتساب ولا شيتات ولا تقارير كاملة** في هذه القناة. هذه تُسجَّل كـ «سؤال لنيكست الكبير» في الـ Inbox.
- **عدّاد التكلفة تقديري** ويحسب الحد الأعلى: 0.023$ لكل دقيقة مكالمة. الرقم الفعلي في Google Cloud Billing.
- **المفتاح في المتصفح:** Google توصي بالرموز المؤقتة (ephemeral tokens) للتطبيقات العامة. هنا المستخدم واحد والمفتاح محفوظ في جهازه فقط، فالخطر مقبول. الحماية الإضافية هي حد الميزانية.

## التجربة على الماك (للتطوير)
```
python3 sync/next_voice_sync.py --index-only --out web/local-index.json
python3 -m http.server 8765 --directory web
```
ثم افتح `http://localhost:8765/#local` (يقرأ الفهرس المحلي ولا يكتب شيئاً).

## مكان الكود والنشر
- النسخة الدائمة على الماك: `~/Documents/next-voice` (هذا المستودع). مهمة launchd `com.elwalid.nextvoice.sync` تشغّل `sync/next_voice_sync.py` منها مباشرة كل دقيقتين.
- تعديل الصفحة: عدّل الملفات هنا ثم `git push`، فينشرها GitHub Pages خلال دقيقة.
- السجل: `~/Library/Logs/next-voice-sync.log`، وحالة المزامنة في `~/.local/share/next-voice/state.json`.
